# Navimow 动效模式库（Motion Patterns）

Navimow 专题页/详情页的动效与交互模式集合，以及「什么动效会被用户打回」的红线。

## When to Use

- 页面要加动效/交互时（scroll 驱动、进场出场、hover、数字滚动、轮播）。
- 用户提到「Apple / DJI 详情页那种感觉」的滚动驱动交互。
- 触发词：动效、滚动、scroll、进场、出场、3D、tilt、count-up、数字滚动、渐显。

## 核心动效语言

用户偏好的方向是 **Apple / DJI 详情页式「滚动驱动交互」**，明确要求：自主决策不询问、
不计开发成本。常用模式：

| 模式 | 说明 | 参考参数 |
|---|---|---|
| scroll-pin | 滚动到某 section 时钉住视口，内部做分步叙事 | 按内容分步 |
| 进场/出场 | 元素随滚动进入/离开视口时淡入/上移 | opacity + translateY 8px |
| 3D tilt | 卡片跟随鼠标倾斜 | `rotateX ±6° / rotateY ±8°`、`perspective 800px`、`lerp 0.12` |
| count-up | 数字从 0 滚到目标值 | rAF 插值 |
| hover scale | 媒体轻微放大 | `scale 1.05`、`0.7s` 缓动 |
| 无缝循环轮播 | 首尾衔接无限循环 | BUFFER clone + 瞬跳，见 component-build |
| 布局级过渡 | 卡片宽度/展开收起 | 双层交叉淡化 + 固定宽度幕帘，≈0.4s |

## 微动效尺度（红线，用户两次打回后定稿）

这是最容易被忽略、也最容易被打回的部分：

1. **文字渐显 / 文字出现类动画 = 「晃眼睛」**，用户明确要求移除过（如手风琴描述文字）。
   不要做「段落逐字/渐显/淡入浮现」这类效果。
2. **但无过渡的瞬切同样被嫌「生硬」**。所以不是「去掉动画」，而是「换一种动画」。
3. **可以做的**：布局级过渡（容器宽度变化、卡片展开收起）。
   正解是 **双层交叉淡化 + 内容层固定宽度幕帘**：先淡出（~0.2s）→ 换内容 → 再淡入
   （~0.2s），总感知 ≈0.4s。内容层宽度固定，避免文字在过渡中回流重排。

## 判断口诀

- 动的是「**位置/尺寸/容器**」→ 可做（布局级过渡）。
- 动的是「**文字本身的出现/消失**」→ 慎做，大概率被打回。
- 拿不准就做「交叉淡化 + 固定宽度幕帘」，这是已验证的最优解。

## 坑

- 3D tilt 的 `perspective` 要设在**父容器**上，设在被倾斜元素自身无效。
- 程序化 SVG 动效（如桂冠、叶片）旋转角注意本地基准（叶片「朝上」基准要 +90°）。
- 连续快速触发时加防抖/动画锁，避免文字闪跳、连点穿帮。
