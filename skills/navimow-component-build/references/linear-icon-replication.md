# 线性 SVG 图标复刻（参考图 → 描边图标）工作流

来源：2026-09-24 手套+螺丝刀图标两次任务（横叠版 v1 / 立式五指版 v2，参考 Shutterstock 图）。

## 交付约定

- 位置：`Navimow/设计/icons/<name>.svg`（图标本体）+ `preview[-vN].html`（多尺寸检查页，与图标同目录，`<img src>` 相对引用）。
- 规格：`viewBox="0 0 64 64"`、`fill="none" stroke="currentColor"`、`stroke-linecap/linejoin="round"`，描边 2–2.4px。`currentColor` 使暗色背景自动反白。
- 检查页四格：256px（放大查细节）/ 96px / 48px（小尺寸可用性）/ 暗色背景 64px。

## 迭代循环（每版必做）

1. write_file 写 SVG。
2. write_file 写/更新 preview HTML（新版本号新文件，保留旧版可对比）。
3. `browser_navigate` 打开 preview HTML 的 file:// URL。
4. `browser_vision` 带具体问题清单（各元素是否可辨、哪里线条糊住/打架、构图是否接近参考图）。
5. 按反馈 patch 后重开页面复验。一个图标通常要 2–4 版。

## 已验证的坑

- **`<use href="file.svg#id">` 在 file:// 自动化浏览器里不渲染**（跨文件引用被拦）。检查页放大格一律用 `<img src="xxx.svg" width="256">`。
- **mask 黑白方向**：mask 内白色=显示、黑色=隐藏。做遮挡关系是「白底全屏 rect + 黑色挖洞形状」，写反会把下层元素整个遮没（表现为图标只剩前景工具）。
- **小尺寸下斜穿元素与复杂轮廓重叠必糊**：第一版双手套横叠 + 螺丝刀斜穿，线条全部打架认不出。解法是简化为单笔轮廓（手套一笔 path 含拇指，四指用圆头横线/缺口表达），并让前景元素路径避开袖口等横向线。
- **遮罩挖洞要收窄**：挖洞宽度=前景元素宽度会连带把后面元素的特征（如手指）挖秃、把底边横线挖断。挖洞比前景本体略窄，被断开的横向线必要时单独 `<line>` 补回可见段。

## 造型技法（参考图复刻）

- 五指张开的手套/手型：每根手指独立 `V` 段 + 指根圆角过渡，拇指用斜向 C 曲线凸出；后侧手套整体 translate 错位叠放。
- 遮挡关系标准做法：下层元素包在 `<g mask="url(#occl)">`，挖洞形状组与前景元素共用同一个 `transform="translate(x y) rotate(a)"`，挖洞坐标按前景本地坐标系写，保证洞与前景严丝合缝。
- 螺丝刀类工具：细杆 line + 刀尖加粗短线 + 箍环小 rect + 胶囊手柄大 rect + 手柄内两道握纹线，全部放同一个 rotate 组里画成水平再整体旋转，比直接写斜坐标可靠。
