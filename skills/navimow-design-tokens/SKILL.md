# Navimow 品牌设计语言（Design Tokens）

Navimow 官网/产品页所有复刻、组件、专题页必须遵守的品牌视觉规范。
机器可读版见 `references/tokens.json`（脚本可直接消费）。

## When to Use

- 任何 Navimow 页面/组件需要「用什么颜色、什么字体、多大圆角」时。
- 触发词：品牌色、主色、字体、字号、Inter、圆角、间距、token、3D 图标配色、奶油白、砖红。

## 颜色 Token

| Token | 值 | 用途 |
|---|---|---|
| 品牌主色 accent | `#FF5A00` | CTA / 高亮 / 播放指示点 |
| 主文字 ink | `#1F1F1F` | 深色主题文字、正文 |
| 纯黑 | `#000000` | 深色页面底色 |
| 页面底 | `#FFFFFF` | **默认白底**（用户要求，非必要不做黑主题） |
| 非当前项卡片底 | `#F7F7F5` | 轮播/卡片非激活态 |
| 媒体上标题 | `#FFFFFF` | 压图文字 |
| 媒体上副标题 | `rgba(255,255,255,.70)` | 压图副文案 |
| 遮罩渐变 | `rgba(0,0,0,.55)→transparent` | 媒体底部文字可读性 |

## 字体 Token

- 字体族：**Inter**（Google Fonts），回退 `system-ui, -apple-system, sans-serif`
- 字重：`400` 正文 / `600` caption / `700` 标题 / `800–900` 仅 campaign 大标题
- 常规页面标题用 700，**不要**随意用到 800/900（那是 Creators 这类 campaign 页专属）

## 圆角 / 间距 / 尺寸

| Token | 值 | 来源 |
|---|---|---|
| 卡片圆角 | `16px` | 拼贴卡片墙 |
| 卡片间距 gap | `32px`（移动 `20px`） | TrustBar |
| 紧凑 gap | `16px` | 拼贴卡片墙 |
| 卡片内边距 | `16px` | 拼贴卡片墙 |
| logo 统一高度 | `96px`（移动 `64px`） | TrustBar |

## 3D 图标配色系统（哑光软胶质感）

- 三色系（每块形状一个 linearGradient，浅→深同色系，明暗差约 20%）：
  - 奶油白 `#FBF7EF → #EBE1CE`
  - 深蓝 `#3D5BD9 → #2743A8`
  - 砖红 `#CE4658 → #A82C3E`
- 质感 = 渐变本身 + 白色高光条/椭圆高光；**不要投影**。
- 厚圆角：`rect rx ≈ 高度的 20–25%`；图标容器 64px，不加底色方块。

## 铁律

1. 默认白底 `#FFFFFF`、文字 `#1F1F1F`，除非明确要求深色。
2. 层次靠「底色 + 边框深浅」区分，**不靠阴影**（用户移除过全部 box-shadow）。
3. 改动共享 token 前，先确认影响范围（同一 token 可能被多模块复用）。
