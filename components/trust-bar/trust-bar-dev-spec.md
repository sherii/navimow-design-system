# TrustBar 奖项信任背书组件 — 开发设计说明

> 版本 v3.4 ｜ 交付 2026-09-08 ｜ 设计：陈景雷（DTC UI/UX）
> 参考实现（像素级基准）：`设计系统/组件/trust-bar/trust-bar.html` + `assets/`
> 模块定位：产品详情页 / 首页的「Awards & Recognition」信任背书模块

---

## 1. 模块结构总览

```
┌─────────────────────────────────────────────────────┐
│  [桂冠左]   主标题 H2（随奖项变化）        [桂冠右]   │  ← 头部 tb-head
│             副标题 p（随奖项变化）                    │
├─────────────────────────────────────────────────────┤
│  ◄ 渐隐 │ 卡片 卡片 [当前卡片] 卡片 卡片 │ 渐隐 ►   │  ← 轮播 tb-viewport
│                （当前项始终居中）                     │
└─────────────────────────────────────────────────────┘
```

- 头部（标题 + 可选桂冠）与下方轮播**联动**：轮播切到哪个奖项，头部就显示哪个奖项的文案
- 轮播为**居中式**：当前项永远位于视口正中，左右对称露出相邻卡片
- 无箭头、无圆点指示器（评审确认过移除），全部交互只靠轮播自身

## 2. 数据结构（驱动一切的源）

组件完全数据驱动，开发按此结构接 CMS/JSON 即可：

```js
{
  name:     "iF Gold Award 2022",              // 奖项全称（alt + aria-label 用）
  org:      "iF International Forum Design",   // 颁奖机构/媒体名
  src:      "if-22-gold-award.svg",            // logo 图（assets 相对路径）
  laurel:   true,                              // 选配：头部是否显示桂冠
  headline: "iF Gold Award 2022",              // 选配：头部主标题（支持 \n 换行）
  subline:  "Navimow H Series — Top 1% …",     // 选配：头部副文案
}
```

**回退规则（重要）**：
- `headline` / `subline` 缺省 → 头部回退到默认文案
  - 默认主标题：`Award-Winning Robot Mowers,<br>Recognized Worldwide`
  - 默认副标题：`Honored by 30+ leading media and design institutions across Europe & North America.`
- `laurel` 缺省 / false → 桂冠隐藏
- 当前数据：35 项（4 个设计大奖配桂冠，其余媒体奖不配），开发注意留出增删项的配置能力

## 3. 交互逻辑（核心）

### 3.1 自动轮播
| 参数 | 值 | 说明 |
|---|---|---|
| 停留时长 `autoplay` | **4500ms** | 对齐 Hypershell 站实测节奏 |
| 切换过渡 `speed` | **700ms** | 缓动 `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint 类） |
| 方向 | 永远向前（向左滑动） | 自动播放只进不退 |

### 3.2 用户交互
| 交互 | 行为 |
|---|---|
| **点击当前项右侧的卡片** | 轮播正向滑到该卡（=「下一张」方向） |
| **点击当前项左侧的卡片** | 轮播反向滑到该卡（=「上一张」方向） |
| **hover 到轮播区域** | 暂停自动轮播（清除 timer）；移出后**立即恢复**并重新计时 4.5s |
| **键盘 Tab 聚焦卡片 + Enter/空格** | 等同点击该卡片 |
| **点击时若动画进行中** | 忽略该次点击（`animating` 锁，见 §5） |
| **窗口 resize** | 无过渡地重新对齐当前项居中（防止错位） |

⚠️ 关键细节：用户点击某张卡后，自动播放计时器要**重置**（重新计满 4.5s 再走下一张），不能从上次的剩余时间继续。

### 3.3 头部联动（标题 + 桂冠）
轮播每次切换（自动或手动），头部做一次「淡出 → 换内容 → 淡入」：

```
时序：is-switching 类加上（透明度 1→0、上移 8px 回落，300ms）
  → 300ms 后替换 headline / subline 文本，同时桂冠按 laurel 字段显隐
  → 移除 is-switching（透明度 0→1，300ms）
```

- 桂冠显隐动画：透明度 0→1 + scale 0.85→1，500ms
- 连续快速切换时用**防抖**：每次切换清掉上一次未完成的替换 timer，避免文字闪跳
- **桂冠是选配**：只有 `laurel: true` 的奖项显示（当前为红点/iF/iF Gold/Best of CES 四个设计大奖）；桂冠消失时头部文字区自动重新居中（flex 布局，桂冠元素占位不塌陷——用 opacity/scale 隐藏而非 display:none，见 §6）

## 4. 无缝循环实现（重点，需要严格按此方案）

采用**克隆缓冲区（buffer clone）+ 瞬时回跳**方案，这是保证「任意方向都无缝」的成熟做法：

### 4.1 渲染结构
```
[最后8张克隆] + [35张真实] + [前8张克隆]  →  共 51 个 slide 排成一条轨道
```
- 缓冲区大小 `BUFFER = 8`，须满足 ≥（视口同时可见卡片数 + 3）；当前 1440px 下最多可见 5 张，8 足够
- 克隆卡带相同 `data-index`，真实索引用于状态同步（is-active 高亮）

### 4.2 滑动与回跳
1. 每次切换：从当前位置**沿滑动方向**找最近的、`data-index === 目标` 的克隆卡，带 700ms 过渡滑过去
2. 滑动结束（+30ms 余量）后检查：若已滑进尾部缓冲区（`pos ≥ n + BUFFER`）或头部缓冲区（`pos < BUFFER`），则**无过渡瞬间跳回**中间整组的等价位置（`BUFFER + current`）
3. 瞬跳后强制一次回流（`void stage.offsetWidth`）再恢复 transition，否则下一次切换会闪跳
4. 动画锁：切换期间 `animating = true`，结束（含回跳）后释放；期间所有点击/自动触发忽略

### 4.3 轨道数量与 BUFFER 的自适应规则（数据源变化时必读）

轨道 slide 总数不是固定值，按公式计算：

```
轨道总数 = 真实数量 N + 2 × BUFFER
```

| 真实数量 N | 轨道总数（BUFFER=8） |
|---|---|
| 35（当前） | 51 |
| 20 | 36 |
| 10 | 26 |

**BUFFER 按什么定**：BUFFER 是按「视口同时可见的卡片数」定的，与真实总数无关：

```
BUFFER ≥ 可见卡片数 + 3（安全余量）
```

- 桌面 1440px：卡片 280 + gap 32 → 一屏最多约 5 张 → BUFFER=8 ✓
- 改了卡片尺寸 / gap / 断点导致可见数变化 → BUFFER 跟着重算
- `goTo` 的回跳条件（`pos ≥ N + BUFFER` / `pos < BUFFER`）使用变量 N，**数据增减无需改代码**

**真实数量变化时的验证点**：

- [ ] N=20：轨道 36 个；快速连点 5+ 次（动画锁天然限速），确认不滑出缓冲区尽头、无白底
- [ ] 直接点击视口内最远的卡（如当前第 1 张、点右侧第 5 张）：goTo 沿方向找最近克隆，位移在安全范围内
- [ ] N 减少后回跳仍瞬时无感（两侧内容一致）

**下限建议**：N 少到个位数（如 8 张）时，BUFFER 至少 8，且建议 **N ≥ 2 × 可见数**，否则一个循环内重复感明显，应考虑改用普通（非循环）布局或补充奖项数量。

### 4.4 验收标准
- 从第 1 张点「上一张」→ 反向滑出最后一张，**无跳变、无空白**
- 从最后一张点「下一张」→ 正向滑回第 1 张
- 自动播放连续运行 10 分钟以上不出错位/累积偏移
- 数据源增减（如 35→20 张）后轨道总数 = N + 2×BUFFER，循环行为不变（见 §4.3）

## 5. 状态与样式细节

### 5.1 卡片状态（共 3 态）
| 状态 | 透明度 | logo 滤镜 | 备注 |
|---|---|---|---|
| 当前项 `is-active` | 1 | 彩色（无滤镜） | 始终居中 |
| 非当前 | 0.5 | 灰度 `grayscale(1) brightness(1.05) contrast(1.02)` + 自身 opacity .82 | 两侧压暗 |
| hover（非当前） | 1 | 彩色 | 预览意图，但不改变当前项归属 |

- **卡片本身无背景、无边框、无阴影**（v3.3/v3.4 确认移除），白底透出
- logo 统一高度 **96px**（移动端 64px），宽自适应、`object-fit: contain`，最大宽 224px
- logo 上 `pointer-events: none`——点击事件统一落在卡片容器上，避免 img 拦截
- 切换状态过渡：opacity 450ms、filter 350ms，缓动同 §3.1

### 5.2 两端渐隐遮罩
视口用 mask 实现左右渐隐（不是叠加渐变 div）：
```css
mask-image: linear-gradient(90deg, transparent, #000 7%, #000 93%, transparent);
```
需要 `-webkit-mask-image` 兼容写法。渐隐范围各 7%。

### 5.3 头部排版
- flex 横排居中：`桂冠(72×110) — 36px 间距 — 文字块 — 36px 间距 — 桂冠(镜像)`
- 主标题：Inter 700，`clamp(28px, 3.2vw, 44px)`，行高 1.15，letter-spacing -0.02em，最宽 680px
- 副标题：Inter 400 15px，色 `#8C8C8C`（rgba(31,31,31,.56)）
- 头部最小高度 150px：**防止桂冠显隐、文字换行数变化时头部高度跳动**
- 右桂冠 = 左桂冠 `scaleX(-1)` 镜像

### 5.4 桂冠素材
程序化生成的 SVG（贝塞尔弧线 + 10 片交替柳叶形叶片，叶长向顶端递减），**不是位图**：
- 实现：头部两个容器（左/右）由 JS 注入同一 `laurelSVG()`，右侧整体 scaleX(-1)
- 开发可直接把参考实现里生成的最终 SVG 抠成静态 .svg 文件，效果等价；叶片颜色 `#1F1F1F`
- 设计源文件见 `trust-bar-figma.svg`（内含矢量桂冠，可直接导出 SVG 用）

## 6. 响应式

断点：**768px**

| Token | 桌面 | 移动端 |
|---|---|---|
| logo 高 | 96px | 64px |
| 卡片宽 | 280px | 200px |
| 卡片高 | 200px | 140px |
| 间距 gap | 32px | 20px |
| 模块上下 padding | 104px / 116px | 64px / 72px |
| 头部 margin-bottom | 72px | 48px |

标题字号用 `clamp()` 流式缩放，移动端约 28px。缓冲区大小在移动端可见卡片更多（4~5 张竖屏）时依然够用。

## 7. 可访问性

- 模块容器：`role="region"` / `aria-label="Awards and recognition"`
- 每个卡片：`role="button"` + `tabindex="0"` + `aria-label="{奖项名} — {机构名}"`（机构名虽然视觉上移除了，aria-label 必须保留）
- logo `alt` = 奖项名
- 桂冠容器 `aria-hidden="true"`（纯装饰）
- `prefers-reduced-motion: reduce` 时：关闭所有 transition，自动轮播建议直接停用（参考实现关了过渡，开发可进一步把 interval 不启动）
- 键盘可完整操作：Tab 逐卡聚焦 → Enter/空格查看

## 8. 实现注意事项（坑位清单）

1. **动画锁**：`goTo` 全程持锁，切换 700ms + 回跳期间忽略新触发，否则快速点击会错位累积
2. **瞬时回跳必须无过渡**：`transition: none` 设置后要强制回流再恢复，Chrome/Safari 都会吞掉同帧的样式变更
3. **hover 暂停的恢复**：mouseleave 时 `restartTimer()`（重新起 interval），不是恢复剩余时间——保持与 Hypershell 一致的「移出后重新等 4.5s」
4. **点击重置计时**：手动切换后必须重置 autoplay timer
5. **logo 素材是内嵌位图的 SVG**（35/37 个是 Figma 导出的 `<image>` 包 PNG），前端直接 `<img>` 引用即可；**不要**尝试 inline 后改 fill 做单色化——单色化用 CSS filter 已实现
6. **图片懒加载**：`loading="lazy"` 可保留，但首屏若直接可见可改 eager，避免首帧闪灰
7. **resize**：只做无过渡重对齐，不要重建 DOM（克隆结构不变）
8. **头部防抖**：syncHead 的 300ms 换字 timer 必须每次清除重设，快速连续切换时保证最终显示正确
9. **reduce-motion 下回跳**：过渡被禁用后，setX 瞬跳逻辑不受影响，但建议连 autoplay 一起关掉
10. **多实例**：若同一页面要放多个 TrustBar（如首页+产品页组件复用），注意 `document.querySelector` 需改为实例内作用域查询
